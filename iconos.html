Pack de íconos del sistema

Íconos de línea (SVG), listos para usar en cualquier página. Clic en una tarjeta para copiar el código.

Cómo usarlos

El sprite ya está incluido en _layouts/default.html, así que en cualquier página del sitio puedes escribir directamente:

<svg class="icon"><use href="#icon-NOMBRE"></use></svg>

Tamaños: agrega icon-xs, icon-sm, icon-lg o icon-xl junto a icon. Colores: icon-primary, icon-soft, icon-presente, icon-ausente, icon-tardanza, icon-excusa — o cualquier color propio, ya que el ícono hereda currentColor. Para generar íconos desde JavaScript (tablas dinámicas, etc.), arma el mismo HTML como string e insértalo con innerHTML.
